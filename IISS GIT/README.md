# IISS - Intelligent Interview Simulation System

IISS is an AI-powered interview simulation project designed to help candidates practice realistic interviews, receive multimodal feedback, and improve their communication performance before meeting real recruiters.

The project combines AI avatar interaction, speech analysis, facial-expression analysis, tone analysis, verification, and interview workflow design into a complete smart interviewing experience.

## Project Highlights

- AI interview simulator with avatar-driven interaction.
- Speech-to-text and text-to-speech workflow support.
- Facial-expression, eye-tracking, tone, and multi-face analysis modules.
- Candidate verification and mobile experience considerations.
- Complete documentation, presentation, research references, diagrams, demo video, and marketing collateral.
