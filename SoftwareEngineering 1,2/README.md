# Car Service Center - Software Engineering 1 and 2

This repository presents a complete Software Engineering 1 and Software Engineering 2 case study for a Car Service Center system. It combines requirements engineering, UML modeling, architecture design, Java implementation, JSP/Servlet web development, database access, and test artifacts in one organized GitHub-ready structure.

The repository is designed as a polished academic and technical portfolio project.

## Repository Structure

| Folder | Purpose |
| --- | --- |
| [docs/](docs/README.md) | Requirements, use-case material, testing documents, and team documentation. |
| [diagrams/](diagrams/README.md) | Use-case, activity, architecture, class, and sequence diagrams. |

## Technology Stack

| Area | Technologies |
| --- | --- |
| Programming | Java |
| Domain prototype | Maven, Java 21 |
| Web application | Java EE, Servlets, JSP |
| Web server tooling | NetBeans Ant project, GlassFish-style configuration |
| Database | Apache Derby through JDBC |
| Frontend | JSP, HTML, CSS, JavaScript |
| Libraries | Gson |
| Testing | TestNG |
| Modeling | UML, Draw.io, Simple UML `.simp`, Word/PDF design artifacts |

## Main Capabilities

- Customer registration and login.
- Service browsing.
- Booking flow.
- Schedule viewing.
- Technician assignment concepts.
- Booking status management.
- Card payment and cash payment workflows.
- Review and feedback concepts.
- Admin service-management concepts.
- Design-to-implementation traceability from SE1 to SE2.
