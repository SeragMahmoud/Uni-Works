# Repository Management Guide

## Naming Convention

Use clear, readable folder names and keep source code under `source/`.

```text
CompanyProject.sln
CompanyProject/
Company.DAL/
Company.Reposatory/
```

## Folder Rules

- Keep the Visual Studio solution and C# projects in `source/`.
- Keep technical documentation in `docs/`.
- Keep diagrams in `diagrams/`.
- Keep screenshots and demo media in `demo/` or `assets/`.
- Keep reports in `reports/`.
- Keep supporting historical material in `archive/`.

## Recommended GitHub Presentation

1. Root README for project overview and quick start.
2. `docs/` for technical depth.
3. `diagrams/` for visual architecture.
4. `demo/` for screenshots and screen recordings.
5. `.gitignore` for generated .NET and Visual Studio files.
