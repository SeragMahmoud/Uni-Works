# Workflows

## Account Workflow

1. User opens the login page.
2. New users register through the account registration form.
3. Registered users log in with email and password.
4. Successful login redirects to the home page.

## Department Workflow

1. User views department list.
2. User creates departments.
3. User reviews department details.
4. User updates department information.
5. User deletes departments through the MVC workflow.

## Employee Workflow

1. User views employee list.
2. User creates employees and assigns them to departments.
3. User updates employee information.
4. User deletes employees through the MVC workflow.
