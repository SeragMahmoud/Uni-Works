# IISS Diagrams

This folder contains reviewed diagram exports and editable source files recovered from the read-only original project documentation. Filenames were normalized for GitHub navigation while preserving the original diagram content.

## Contents

- [architecture](architecture/) - System architecture, block diagram, and website map.
- [flowcharts](flowcharts/) - End-to-end and module-level processing flows.
- [uml](uml/) - Exported UML, ERD, sequence, package, object, and communication diagrams.
- [sources](sources/) - Editable `.simp` UML files and the ERDPlus source.

## Suggested Review Path

1. Start with [architecture/System_Architecture.png](architecture/System_Architecture.png).
2. Review [architecture/Block_Diagram.png](architecture/Block_Diagram.png) and [architecture/Website_Map.jpg](architecture/Website_Map.jpg).
3. Walk through [flowcharts/System_Flowchart.png](flowcharts/System_Flowchart.png), then the module flowcharts.
4. Use the [UML exports](uml/) and [editable sources](sources/uml/) for structural detail.

The Mermaid diagrams in [../README.md](../README.md), [../docs/TECHNICAL_ARCHITECTURE.md](../docs/TECHNICAL_ARCHITECTURE.md), and [../docs/DATABASE_DESIGN.md](../docs/DATABASE_DESIGN.md) remain the lightweight public documentation view. This folder preserves the original exported diagram evidence.
