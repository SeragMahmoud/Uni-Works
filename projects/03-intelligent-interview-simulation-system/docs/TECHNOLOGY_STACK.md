# Technology Stack

| Layer | Technology |
| --- | --- |
| Backend | Node.js, Express, ESM modules |
| Database | MongoDB with Mongoose models |
| Authentication | JWT, bcryptjs |
| Realtime | `ws` WebSocket server |
| Uploads | multer |
| Frontend | Flutter/Dart, Provider, HTTP services |
| Media | Camera, audio recording, TTS audio payloads |
| AI integration | HTTP and WebSocket AI backend, DeepSeek workflow references |
| Supporting modules | CV parsing, billing, payment, subscription, admin, support |
