# Project Overview

IISS is an AI interview-practice system with candidate and recruiter workflows. The project is represented here as a sanitized portfolio case study because the Original implementation contains sensitive environment files, logs, local URLs, generated artifacts, and large model/media assets.

## Product Capabilities Evidenced In Source

| Capability | Evidence found in Original |
| --- | --- |
| Authentication and roles | Auth route/service structure, candidate/HR/admin route files, JWT dependencies. |
| Interview configuration | HR interview configuration services and Flutter multipart upload flow. |
| Realtime interview | Node `ws` WebSocket bridge and Flutter interview service. |
| AI backend orchestration | HTTP and WebSocket AI client helpers, AI session init/end/feedback flow. |
| Feedback reports | Metric mapping for tone, expression, gaze, communication, and technical relevance. |
| Identity verification | Verification flow notes and route/model/service changes in Original reports. |
| Product UX | Web/mobile screenshots, landing page, feedback report, dashboards. |
| Research grounding | Research papers, comparison tables, presentation, and documentation packages in Original. |

## Publication Boundary

Included:

- Public-safe screenshots.
- Accurate architecture and workflow diagrams.
- Sanitized code excerpts and source-provenance notes.
- Setup/review guidance.

Excluded:

- `.env` files and secrets.
- Logs and private test credentials.
- Large archives, models, generated builds, and datasets.
- Identifiable webcam screenshots and raw demo videos.
- Copyrighted third-party research PDFs.
