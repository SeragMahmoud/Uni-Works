# Operation

## Physical Game Mode

```bash
python src/chess_arm/test_moves.py
```

## Dashboard Mode

```bash
python src/chess_arm/main.py
```

## Direct Arm Test

```bash
python src/chess_arm/chess_arm_controller.py e2e4
```

## Controls

| Key | Action |
| --- | --- |
| `SPACE` | Lock board reference. |
| `R` | Reset game state. |
| `Q` | Quit. |
