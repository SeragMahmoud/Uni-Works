# Features

- Camera board observation with OpenCV.
- Frame-difference move detection over a calibrated board ROI.
- Legal move filtering through `python-chess`.
- Stockfish engine response generation.
- Serial command protocol with firmware acknowledgements.
- Servo lookup-table generation for all 64 squares.
- Pick/place motion sequence with hover and ground poses.
- Board ROI calibration utility.
- Servo range validation utility.
- Optional YOLO/OpenCV piece-detection experiment.
- Tkinter dashboard mode.
