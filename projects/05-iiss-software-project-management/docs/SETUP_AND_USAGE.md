# Setup And Usage

No software setup is required.

## Review Path

1. Start with `README.md`.
2. Review `docs/PROJECT_OVERVIEW.md` for the artifact catalogue.
3. Review `docs/TECHNICAL_ARCHITECTURE.md` for lifecycle and PMBOK mapping.
4. Review phase folders under `docs/`.
5. Review `repository-management.md` for organization standards.

## Working With The Private Source

If the owner has access to the private Office files, export public-safe PDF or image summaries before adding them. Remove author metadata and private comments before publication.
