# IISS Software Project Management Case Study

## Overview

This project presents the Software Project Management work behind the IISS graduation project. It organizes project-management material by lifecycle phase and summarizes planning, scheduling, communication, risk, change control, and closure practices.

## Purpose

The project demonstrates PMBOK-inspired software project management for an AI-enabled graduation project.

## Main Features

- Initiation documentation structure.
- Planning documentation structure.
- Monitoring and control documentation structure.
- Closure documentation structure.
- Microsoft Project schedule organization.
- Repository management guidance.
- Communication, training, RAID, change, and closure artifact indexes.

## Technology Stack

Microsoft Project workflow, Microsoft Word/PowerPoint planning artifacts summarized through Markdown, PMBOK-inspired project management, GitHub documentation structure.

## Architecture

```text
Initiation -> Planning -> Monitoring and Control -> Closure
```

| Folder | Purpose |
| --- | --- |
| `docs` | Lifecycle documentation indexes. |
| `microsoft-project` | Schedule-source index. |
| `diagrams` | WBS, Gantt, milestone, and network diagram index. |
| `presentations` | Presentation-material index. |
| `reports` | Report index. |
| `templates` | Template index. |
