# Demo Review Guide

This is a documentation case study. No runtime demo is required.

## Review Flow

1. Read `README.md`.
2. Review `docs/PROJECT_OVERVIEW.md` for the original artifact catalogue.
3. Review `docs/TECHNICAL_ARCHITECTURE.md` for lifecycle and governance diagrams.
4. Review phase folders under `docs/`.
5. Review `repository-management.md` for organization standards.

The private Office files are not published; this folder is the GitHub-safe presentation layer.
