# Repository Management Guide

## Folder Rules

- Keep lifecycle documentation indexes in `docs/`.
- Keep schedule summaries in `microsoft-project/`.
- Keep exported visual summaries in `diagrams/`.
- Keep presentation summaries in `presentations/`.
- Keep public reports in `reports/`.
- Keep reusable templates in `templates/`.
- Keep private or opaque binaries out of the public source publish.

## Naming Convention

Use numeric prefixes for ordered deliverables and readable title-case document names when adding public-safe files later.

## Public Publish Policy

This GitHub copy intentionally uses Markdown summaries and folder indexes. Office documents, Microsoft Project binaries, and other opaque files should be reviewed, sanitized, and permission-checked before publication.
