# Diagrams

This folder contains the visual design artifacts for the Car Service Center system.

| Folder | Purpose |
| --- | --- |
| `use-case` | Use-case diagrams. |
| `activity` | Customer and admin activity diagrams. |
| `architecture` | System architecture and MVC diagrams. |
| `class-sequence` | Class diagrams and sequence diagrams. |
| `sources` | Editable diagram source files. |
