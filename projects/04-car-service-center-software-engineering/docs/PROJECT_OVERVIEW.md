# Project Overview

Car Service Center demonstrates an academic software engineering lifecycle. It starts with requirements and UML artifacts, then moves into a Java domain model and JSP/Servlet implementation.

## Lifecycle Coverage

| Phase | Evidence |
| --- | --- |
| Requirements | Functional/non-functional notes and proposal indexes. |
| Analysis | Use-case tables, scenarios, and use-case diagram artifacts. |
| Design | Activity diagrams, architecture diagrams, class diagrams, and sequence diagrams. |
| Implementation | Java Maven domain model and JSP/Servlet web apps. |
| Verification | Generated TestNG model test files. |

## Publication Boundary

Included material focuses on public-safe source and diagrams. Large Office documents, archives, generated builds, local IDE metadata, private database files, and raw credentials are excluded or sanitized.
