# Assets

This folder contains supporting visual assets used by documentation, reports, and presentations.

| Folder | Intended Content |
| --- | --- |
| [images/](images/) | General images and diagrams used in documentation. |
| [screenshots/](screenshots/) | Product, tool, or Microsoft Project screenshots. |
| [gantt/](gantt/) | Gantt chart images exported for README/report embedding. |
| [wbs/](wbs/) | WBS images exported for README/report embedding. |

Prefer descriptive filenames and keep source project files in their dedicated folders.
