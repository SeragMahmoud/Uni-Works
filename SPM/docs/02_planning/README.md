# Planning Documents

This folder contains planning artifacts that define how the project team communicates, prepares stakeholders, manages risk, and aligns individual responsibilities.

| File | Role |
| --- | --- |
| [01_Communication_Plan.docx](01_Communication_Plan.docx) | Defines communication channels, audiences, cadence, and stakeholder messaging expectations. |
| [02_Training_Plan.docx](02_Training_Plan.docx) | Plans training needs and readiness activities for project stakeholders. |
| [03_Individual_Goals.docx](03_Individual_Goals.docx) | Aligns individual responsibilities and personal delivery goals with the project objectives. |
| [04_RAID_Log.docx](04_RAID_Log.docx) | Tracks risks, assumptions, issues, and dependencies for proactive management. |

These artifacts complement the schedule and resource planning captured in [../../microsoft-project/](../../microsoft-project/README.md).
