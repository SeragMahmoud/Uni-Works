# Initiation Documents

This folder contains the documents that justify and authorize the IISS project.

| File | Role |
| --- | --- |
| [01_Feasibility_Study.docx](01_Feasibility_Study.docx) | Evaluates whether the project is viable from practical, technical, and organizational perspectives. |
| [02_Business_Case.docx](02_Business_Case.docx) | Explains the value of the project and the reasoning for investing effort and resources. |
| [03_Project_Charter.docx](03_Project_Charter.docx) | Authorizes the project and defines high-level objectives, scope, roles, milestones, and constraints. |
| [04_SWOT_Analysis.docx](04_SWOT_Analysis.docx) | Assesses strengths, weaknesses, opportunities, and threats to support strategic planning and risk awareness. |

These artifacts support integration, scope, stakeholder, risk, and strategic alignment activities.
